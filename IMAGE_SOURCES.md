# Fandom Verse image sources

The seeded fandom cards use real remote images from Wikimedia Commons so the app can fetch authentic category/fandom imagery at runtime.

- Attack on Titan — Wikimedia Commons, `Attack on Titan.jpg` (CC BY-SA 4.0)
- BTS — Wikimedia Commons, `BTS Arirang World Tour in Paris (17 July 2026) - finale.jpg` (CC BY-SA 4.0)
- Cyberpunk 2077 — Wikimedia Commons, `PGA 2019 Cyberpunk 2077.jpg`
- Demon Slayer — Wikimedia Commons, `Cosplay de Kokushibo Demon slayer.jpg` (CC BY-SA 4.0)
- Marvel — Wikimedia Commons, `Marvel characters.jpg` (CC BY-SA 2.0)
- BLACKPINK — Wikimedia Commons, `Blackpink.jpg`
- One Piece — Wikimedia Commons, `One Piece (8413847339).jpg`
- Halo — Wikimedia Commons, `Halo MCC banner.jpg`

The app intentionally keeps these as remote URLs instead of bundling them, while `FVImage` provides resized loading, memory sizing, loading placeholders, and error fallbacks. Review each source page/license before distributing the app commercially.
